Политика конфиденциальности

Приложение Archive · обновлено 13 октября 2026 года

Archive — личное приложение для архивации собственной электронной почты. Оно работает в интересах одного владельца — владельца архивируемых ящиков — и не является публичным сервисом.

Какие данные обрабатываются

Приложение получает доступ к почтовым ящикам, указанным их владельцем:

  • заголовки писем: отправитель, получатель, тема, дата;
  • текст писем и вложения;
  • метки и папки, в которых находится письмо.

Доступ к ящику Gmail предоставляется по протоколу OAuth 2.0 после явного согласия владельца. Приложение не знает и не запрашивает пароль от ящика.

Зачем

Единственная цель — создать и хранить локальную резервную копию почты владельца и предоставить ему поиск по ней.

Где хранятся данные

Все данные хранятся на собственном сервере владельца в виде файлов писем и локальной базы данных для поиска. Они не загружаются в облачные сервисы третьих лиц.

Передача данных третьим лицам

Данные не передаются, не продаются и не раскрываются третьим лицам. Они не используются для рекламы, профилирования, обучения моделей искусственного интеллекта или любых иных целей, кроме перечисленных выше.

Использование данных Google

Использование приложением информации, полученной через API Google, соответствует Политике использования данных пользователей API Google, включая требования ограниченного использования (Limited Use).

Удаление данных

Владелец может удалить локальный архив в любой момент. Доступ приложения можно отозвать на странице разрешений аккаунта Google; после отзыва доступ прекращается немедленно.
